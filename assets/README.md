# assets

## alhikma-logo.png

Drop the Al Hikma logo here, named exactly `alhikma-logo.png`, and it appears
in the masthead automatically — no HTML or CSS changes needed.

- **Format:** PNG with a transparent background, or swap the `src` in
  `index.html` to `.svg` if you have a vector version.
- **Colour:** the masthead is dark navy (`#06192B`), so use the white or
  light version of the mark.
- **Size:** it is displayed 42px tall on desktop and scales down on phones.
  Supply it at roughly 2x that height (about 84–120px tall) so it stays sharp
  on high-density screens. Width is free — the layout caps it at 130px and
  keeps the aspect ratio.

Until the file exists the masthead simply shows the wordmark text, with no
broken-image icon.
